## Overview

Da Vinci Suture Training Simulator is a browser-based medical simulation game focused on robotic-assisted suturing practice. It provides three training scenarios that progress from grape suturing to human skin and intestinal anastomosis, giving users different procedural contexts to work through.

The simulator combines mouse or mobile touch input with segmented, clutch-style instrument movement. Users can adjust motion scaling, apply hand tremor filtering, manage sutures, and respond to dynamic bleeding and breathing effects while completing each exercise.

---

## Script Features

- Three practice levels: grape, human skin, and intestinal anastomosis
- Motion scaling options of 1:1, 3:1, and 5:1
- Hand tremor filtering for instrument control
- Mouse drag and mobile touch interactions
- Clutch-style segmented movement for surgical instruments
- Dynamic bleeding and breathing effects during simulation
- Suture tying and procedure completion mechanics
- S to F performance ratings with surgical record tracking
- Self-contained HTML format with no external dependencies
